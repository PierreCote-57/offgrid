Pacific Playgrounds Resort

This is a beautiful campground, on the water, with an excellent, well protected marina. There were several larger vessels in the marina, much bigger than your standard fishing boat. There is also a clean, concrete boat ramp.


From a strictly camping point of view, we had a site on the river, giving a beautiful view. When you arrive, make sure to aks for the wifi code and the bathroom code :).
